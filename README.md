# Hydronic Selector Demo - Streamlit

This demo rolls the animated Apple II-style hydronic GIF into the Streamlit app and adds a dynamic callout above the air separator.

## Run

```bash
pip install streamlit pandas
streamlit run app.py
```

## Demo data

- 0-80,000 BTU: Resideo HPV100, 1 inch pipe
- 80,000-140,000 BTU: Resideo HPV125, 1-1/4 inch pipe
- 140,000-250,000 BTU: Resideo HPV150, 1-1/2 inch pipe
- 250,000-450,000 BTU: Resideo HPV200, 2 inch pipe
