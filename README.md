# Hydronic Selector Demo - Streamlit

Updated demo now includes:

- Air Separator selection by BTU and manufacturer
- Expansion Tank selection by BTU, manufacturer, and System Type
- Dynamic green-screen callout on the animated hydronic diagram

## Run

```bash
pip install streamlit pandas
streamlit run app.py
```

## Expansion Tank System Types

- Copper Baseboard/Radiant
- Cast iron radiators/baseboard
